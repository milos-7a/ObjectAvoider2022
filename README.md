# Object Avoider

Object Avoider is a lightweight 3D arcade game where the player controls a ball that must dodge randomly placed red rectangles appearing in front of it. The game is simple, fast-paced, and focused on reaction and survival.

## Gameplay

- Control a ball that moves forward through a 3D environment.
- Avoid red rectangular obstacles that appear at random positions.
- Your score increases as you survive longer.
- The higher your score, the faster the ball moves.

## Features

- Simple 3D gameplay
- Randomly generated obstacles
- Score-based speed increase
- Easy-to-understand mechanics

## Controls

- Move the ball using the keyboard arrow controls configured in the game.
- Avoid collisions with the red obstacles to keep playing.

## Project Notes

This project is a small Unity-based game created as a casual obstacle avoidance experience.
